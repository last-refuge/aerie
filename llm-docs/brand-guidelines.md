# Aether — Brand & Creative Direction

Aether is a premium, Linux-native Google Drive experience. The brand should feel elegant, fast, atmospheric, and distinctly modern—more like a beautifully crafted operating-system feature than a conventional cloud-storage utility.

The visual direction establishes the foundation: a luminous, intertwined cloud symbol, deep midnight surfaces, electric blue and violet gradients, restrained typography, and cinematic imagery.

## 1. Brand identity

- **Product name:** Aether
- **Descriptor:** Google Drive for Linux
- **Primary tagline:** Your files, everywhere.
- **Brand promise:** Your cloud, at home on Linux.

**Positioning statement:** Aether brings Google Drive into the Linux desktop through an experience that feels native, effortless, and beautifully integrated.

The brand should communicate four qualities: speed, seamlessness, precision, and quiet sophistication.

### Voice and personality

Aether speaks with confidence, clarity, and restraint. Its copy should be concise, technically credible, and approachable.

Examples:

- “Your Drive. Right where it belongs.”
- “Everything in sync.”
- “The cloud, without the friction.”
- “Built for Linux. Designed to disappear.”
- “Your files are already home.”

Avoid exaggerated performance claims, excessive technical jargon in consumer-facing screens, and playful language that undermines the premium aesthetic.

## 2. Logo system

The intertwined cloud mark is the central brand asset.

Its three-dimensional, continuous form symbolizes connection between local files, cloud storage, and the user's workflow.

Use four configurations: the standalone symbol for application icons, a horizontal logo for headers and websites, a vertical lockup for promotional material, and a monochrome mark for low-color environments.

The primary symbol uses a cyan-to-blue-to-violet gradient with subtle luminous highlights. Maintain generous clear space around it. Never stretch it, apply drop shadows indiscriminately, or place it over visually busy backgrounds without sufficient contrast.

**Signature gradient:** blue → indigo → violet → cyan

The dark palette should dominate. Use the signature gradient sparingly for the logo, primary actions, progress indicators, and major promotional moments.

Recommended balance: 75% neutral surfaces, 15% typography and structural elements, 10% vibrant accent colors.

## 4. Typography

- **Primary typeface:** Inter
- **Monospace typeface:** JetBrains Mono

Use Inter for navigation, headlines, dialogs, buttons, and body copy. Use JetBrains Mono for file paths, terminal commands, debugging information, and technical metadata.

| Element | Size | Weight |
| --- | --- | --- |
| Marketing hero | 64–80px | 700 |

| Section title | 22px | 600 |

Use slightly tightened tracking on large headlines, comfortable line spacing for paragraphs, and sentence case throughout the product.

## 5. Application design language

Aether should feel native to a carefully customized Omarchy desktop without depending on Omarchy-specific visual conventions.

### Core interface principles

- **Desktop-first.**
- **Calm navigation:** Compact sidebar, clear hierarchy, no unnecessary chrome.
- **Search-first:** Fast global search with keyboard-first interactions.
- **Quiet synchronization:** Subtle indicators, with detail available when needed.
- **Progressive disclosure:** Simple by default, powerful when explored.

### Interface tokens

| Property | Recommendation |
| --- | --- |
| Window background | `#0B1220` |
| Sidebar background | `#101B2D` |

| Card radius | 12px |

| Motion duration | 120–220ms |

For Omarchy and Arch, support dark and light modes, HiDPI scaling, Wayland-friendly window behavior, and user-controlled accent colors.

## 6. Iconography and motion

Use simple line icons throughout the interface. The logo itself may be dimensional and luminous, but the application UI should remain mostly flat and functional.

Motion should reinforce responsiveness rather than attract attention. Sync indicators can rotate gently, file transfers can use smooth progress transitions, and panels can enter with subtle fades or short translations.

Respect reduced-motion preferences. Avoid constant glowing, pulsing, floating, or looping animations in normal desktop use.

## 7. Photography and creative imagery

The imagery should suggest openness, elevation, movement, and possibility.

Use mountain peaks above clouds, atmospheric skies, abstract flowing light, and carefully lit hardware. Favor deep blues, twilight purples, cyan highlights, and occasional warm horizon tones.

Keep imagery cinematic but minimal. Never allow elaborate promotional imagery to spill into everyday file-management screens.

## 8. Brand applications

Aether's visual identity should extend consistently across the website, GitHub repository, application splash screen, system tray, installer, release announcements, and documentation.

For marketing, use dramatic atmospheric compositions with generous whitespace and large typography. For documentation, remove most decorative treatments and prioritize readability, annotated screenshots, and clear technical examples.

For the desktop app, the key test is simple: Aether should look like it belongs on the most thoughtfully designed Linux desktop in the world.
